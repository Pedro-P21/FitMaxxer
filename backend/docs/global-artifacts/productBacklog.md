# FitMaxxer Product Backlog - User Stories

## 1. Physical Profile Management
As a User, I want to log my personal data (age, weight, height, gender, activity level), so that the application can use it as a baseline for my nutritional goals.

## 2. Onboarding and Goal Calculation
As a User, I want to answer questions related to my eating habits and objective (bulk, cut, maintenance), so that the application computes an accurate daily calorie and macro goal for me.

## 3. Manual Goal Editing
As a User, I want to be able to manually edit my macro and calorie goals, so that I am not restricted by the predetermined goals calculated by the application.

## 4. Food Catalog
As a User, I want to be able to search through a catalog of multiple foods, so that I can find and select items to log.

## 5. Meal Logging and Daily Tracking
As a User, I want to be able to log my meals and view a daily summary/graph, so that I can track my caloric and nutrient intake against my goals.

## 6. Daily History
As a User, I want to see the past history of my daily logs, so that I can review what I ate on previous days.

## 7. Custom Foods and Recipes
As a User, I want to be able to create my own custom foods, ingredients, and recipes, so that I can log items that are not available in the public catalog.

## 8. Progress and Trend Tracking
As a User, I want to be able to see a progress trend showcasing changes over time, so that I can evaluate if my nutrition plan is working.

## 9. Authentication and Account Management
As a User, I want to create an account and log in securely, so that my personal data, custom recipes, and history are safely synchronized and saved.

## 10. Editing and Deleting Past Logs
As a User, I want to be able to edit or delete items I previously logged in a meal, so that I can correct mistakes or change my mind about what I ate.

## 11. Meal Duplication
As a User, I want to be able to copy a meal from a previous day into my current day, so that I can save time logging repetitive meals (like breakfast or snacks).
